# Silabín

Aplicación web para que un niño de 3-4 años aprenda a leer en español desde cero: sonidos, vocales y sílabas, con validación por voz, pistas escalonadas y recompensas.

## Estado

En diseño. Ver `docs/superpowers/specs/` para el diseño aprobado y `docs/research/` para la evidencia pedagógica y técnica en que se basa.
